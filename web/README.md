# 브라우저 테스트 클라이언트

`test_client.html` — 로봇 없이 브라우저 마이크로 뇌에 말을 걸어보는 페이지.
`launcher.py`와 같은 프로토콜(§11.5)을 쓴다: `hello` 한 번, 그 뒤로 마이크 PCM16 16kHz를
끊임없이 흘려보내고 턴 경계는 뇌가 정한다(§4). 클라이언트에 VAD는 없다.

## 띄우는 방법

**노트북에서** (AGX가 아니라):

```bash
scp herobot@192.168.0.5:/home/herobot/moti_brain/web/test_client.html .
python3 -m http.server 8000
```

그리고 브라우저로 **`http://localhost:8000/test_client.html`**.

### 왜 localhost여야 하는가

브라우저는 **보안 컨텍스트**(https 또는 `localhost`)가 아니면 `getUserMedia`를 막는다.
그래서 두 경로가 다 안 된다:

- `http://192.168.0.5:8000/...` — 보안 컨텍스트가 아니라 **마이크가 거부된다**
- claude.ai 아티팩트(https) — 마이크는 되지만 https 페이지에서 `ws://`로 붙는 것이
  mixed content로 **차단된다**

`http://localhost`는 보안 컨텍스트로 취급되고, 페이지가 https가 아니므로 `ws://`도 막히지
않는다. 그래서 파일만 노트북으로 옮겨 로컬에서 띄우면 된다.

AGX에서 직접 브라우저를 띄우면 `localhost`라 보안 컨텍스트는 통과하지만,
**AGX에는 마이크가 없다**(트러블슈팅 메모 참고).

### Stage 6 이후

Tailscale을 붙이면 AGX가 `*.ts.net` 인증서를 받을 수 있고, 그러면 뇌를 `wss://`로 열어
아티팩트에서 바로 접속하는 것도 가능해진다. 지금은 위 방법이 확실하다.

## 체크박스 세 개

- **에코 캔슬(AEC)** — 끄면 **로봇에서 AEC가 꺼져 있을 때 무슨 일이 나는지 미리 볼 수
  있다**(§18.1). 스피커로 들으면서 끄면 모티가 자기 목소리에 끼어드는 걸 직접 겪는다.
  이어폰을 쓰면 꺼도 조용하다 — 그게 §9.2가 말하는 격리다.
- **툴 9개 선언** — 끄면 툴이 안 나간다. 켜야 실제 로봇과 같은 조건이고,
  §13.9의 마크업 누출 버그들도 이 조건에서만 재현된다.
- **맞장구** — EXP-12(§12.7). 1.4초 뒤에 "응" 같은 소리가 끼어든다.

## 페르소나

기본값은 짧은 시험용이다. **실제 로봇은 18,344토큰을 보내고 그러면 느려진다**(§13.9:
평균 2.53초, 첫 턴 17.9초). 실제 조건을 보려면 `MOTI-HRI`의
`build_persona_system_instruction()` 출력을 텍스트 영역에 붙여넣는다:

```bash
PYTHONPATH= python3 -c "
import sys; sys.path.insert(0,'/home/herobot/MOTI-HRI')
from core.utils import build_persona_system_instruction as b
print(b(name=None, facts_summary=None))"
```
